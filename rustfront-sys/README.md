# rustfront-sys

Raw FFI bindings to the C API of [MGIS] (MFrontGenericInterfaceSupport).

Every function here is `unsafe`. Use [`rustfront`](https://crates.io/crates/rustfront)
for a safe interface.

> **Status:** early development, nothing usable yet.

See the [repository](https://github.com/Pyrucast/rustfront) for details.

# rustfront

Evaluate [MFront] material behaviours (constitutive laws) at a material point,
in pure Rust.

MFront compiles material behaviours (elasticity, plasticity, creep, …) into
shared libraries. `rustfront` loads the libraries generated with MFront's
`generic` interface and integrates a behaviour at one material point, from
Rust code such as the [pyrucast] finite-element library.

It talks to the generated library directly: no [MGIS], no C or C++ build
dependency, nothing to compile but Rust.

> **Status:** early development. Small strain behaviours, for every
> modelling hypothesis, generated by TFEL 5.1.0 or later.

The arrays of a material point (gradients, thermodynamic forces, material
properties, internal and external state variables) are borrowed from the
caller, who can keep the values of all its points in contiguous storage.
Only loading a library is `unsafe`; integrating is safe.

## Requirements

- Behaviours compiled by MFront (TFEL 5.1.0 or later) with the `generic`
  interface: `mfront --obuild --interface=generic Norton.mfront`.
- Rust 1.88 or later.
- To run the tests, `mfront` in the `PATH`: the tests compile the behaviours
  of `tests/behaviours` and fail without it.

## Try it

With `mfront` and `mtest` (TFEL 5.1.0 or later), `cargo` and `python3` in the
`PATH`:

```bash
./scripts/try.sh
```

The script compiles the test behaviours of `tests/behaviours`, runs the
minimal example, then runs every case of `mtest-rs/cases` with MTest and with
[mtest-rs](mtest-rs), and compares the two result files column by column
with `scripts/compare.py`. Everything it writes goes to `target/try`.

## Minimal example

[`examples/minimal.rs`](examples/minimal.rs) loads a behaviour, prints its
description, integrates it once at one material point and prints the stress
and the tangent operator:

```bash
mfront --obuild --interface=generic tests/behaviours/Elasticity.mfront
cargo run --example minimal -- src/libBehaviour.so
```

## mtest-rs

[mtest-rs](mtest-rs), in this repository, tests a behaviour at one material
point over a loading history: an unofficial, independent reimplementation of
a subset of MTest built on `rustfront`, reading the same `.mtest` files and
writing the same `.res` files.

## Relation to MGIS

[MGIS] is the official library for calling MFront behaviours from a solver,
with C, Fortran, Python and Julia bindings; Rust bindings are on its roadmap
([thelfer/MFrontGenericInterfaceSupport#376](https://github.com/thelfer/MFrontGenericInterfaceSupport/issues/376)).
`rustfront` takes another route: it reads the description each behaviour
exports and calls the behaviour itself, without going through MGIS.
